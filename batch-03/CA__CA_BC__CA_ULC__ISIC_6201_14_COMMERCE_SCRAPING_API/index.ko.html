Export 0% zero-rating conditions

세금법 제6조 제5항에 따라 수출되는 제품은 0% 세율로 적용된다. 서비스에 대해서는 세금법 제6조 제5항 제7조에 따라, 서비스 제공자가 외국 거주자이며 제9조에 따라 등록되지 않았고, 서비스 제공 시에 캐나다에 존재하지 않는 경우, 서비스가 캐나다 내의 부동산 또는 고정자산에 관한 것이 아니며, 서비스가 캐나다 내에서 수행되는 시점에 물리적 소유물에 관한 것이 아니며, 서비스가 캐나다 거주자에게 완전하거나 주로 제공되는 경우를 제외하면 0% 세율로 적용된다. ISIC 6201에 해당하는 상업적 웹 스크래핑 및 프록시 API 게이트웨이 서비스는 외국 파트너와 API 구독 계약을 체결하고, 지불이 캐나다 외부에서 발생하며, 서버 접근 로그, IP 지리정보, API 사용 테레메트리 등의 전달 증거가 해외 소비를 입증하는 경우 수출 서비스로 간주된다. 캐나다 내 소재의 입력 요소(캐나다 내 클라우드 호스팅, 대역폭, 소프트웨어 개발 등)는 입력 세액 공제(세금법 제169조~170조)를 통해 발생하며, 0% 세율 적용 수출이 가산되는 경우 캐나다 내 과세 공급보다 초과하면 GST/HST 신고서에서 순환 환급을 발생시킨다.

外汇管制与央行政策诊断

经常项目兑换自由度

加拿大元具有完全开放的经常账户和资本账户，可以自由兑换。对于外国直接投资、股东出资、公司间贷款、股息汇出或利润回流等事项，不存在一般的外汇管制、资本管制、事先许可或审批要求。货币兑换的自由性仅受标准反洗钱/客户身份识别要求、FINTRAC跨境报告标准、FATCA/CRS自我认证以及常规银行尽职调查的限制。利润汇出可能需要缴纳加拿大第13部分中关于股息、利息、租金或特许权使用费所适用的预扣税，如果适用的话，还可能需要遵守加拿大与美国的税收协定；不过，不存在中央银行或外汇管理机构的任何障碍。

出口外汇强制结汇要求

加拿大对出口收入、跨境软件许可收入以及SaaS订阅收入未设定法定时限、强制转换比例或交还要求。出口商和服务提供商可自行决定将外币保留于境内或境外账户，并自由进行兑换。所有金额达10,000加元或以上的跨境电汇和电子转账，必须由银行、货币服务业务机构及获授权的金融机构根据FINTRAC的电子资金转账报告规则进行申报。因此，ULC必须为所有跨境收入和支付事项保留完整的商业文件支持材料，以满足反洗钱尽职调查要求。

央行监管: 加拿大银行（BoC）与加拿大财政部共同负责，加拿大的外汇管理并未集中于单一监管机构。《货币法》、《外汇管制法》（已大部分废除）、《银行法》以及《犯罪所得（洗钱）及恐怖融资法》共同规范跨境货币交易与报告义务。银行业务及资本充足性的运营监管由金融机构监督官办公室（OSFI）负责，而证券及衍生品市场的交易行为则由加拿大证券监管机构及加拿大银行负责清算与结算系统的监管。

企业所得税 CIT、税表逐栏拆解、股息预提税 WHT 与董事个人法律穿透责任。

法定所得税率 (CIT)

27% 的综合税率（15% 的联邦基础税率 + 12% 不列颠哥伦比亚省一般公司所得税税率）

股息预提税 (WHT)

根据《加拿大所得税法》第十三部分，向非居民股东支付的ULC股息适用25%的税率。

转让定价与经济实质

主文档/本地文档门槛: 当非独立交易的跨境交易的总公平市场价值每年超过100万加元时，必须提供同期转让定价文档。对于合并收入达到或超过7.5亿加元的跨国集团，必须提交主文件和国家间报告。

经济实质审查范围: 加拿大在加勒比地区并无独立的经济实质法规（ESR意义上的规定），但其一般反避税规则（第245条）和转让定价规定（第247条）设定了实质性的经济实质标准。如果一家ULC仅作为税务透明的空壳存在，没有加拿大境内的办事处、雇员或实际业务活动，则可能面临加拿大税务局（CRA）对其性质的重新认定、税收协定利益被拒绝以及被重新评估并附加利息和罚款的风险。

致命合规红线与董事个人责任

逃税 / 重大过失

法定制裁: 根据《税法》第239条，刑事处罚将处以逃税金额50%至200%的罚款，并可处以最高五年监禁。根据《税法》第163(2)条的民事重大过失处罚，为未申报税额的50%加上利息。

董事个人责任: 批准虚假陈述的董事及高级管理人员可能面临刑事指控并被处以个人罚款。根据不列颠哥伦比亚省有限公司法规定，当公司无法清偿债务时，股东对公司义务（包括联邦税款债务）承担无限责任。
转让定价失败

法定制裁: 加拿大税务局可依据第247条重新定价该交易，征收额外税款及滞纳金，并处以相当于重新评估金额10%的罚款（罚款金额以5000加元或调整金额的10%中较高者为准）。

董事个人责任: 董事并非自动对TP处罚承担责任，但如果定价错误构成疏忽或故意忽视，则董事可能根据联邦所得税法对来源扣缴义务的违反承担连带及个别责任，且在不列颠哥伦比亚省（BC）则可能根据无限责任制度（ULC）承担无限连带责任。
空壳公司 / 高收入避税 / 条约滥用

法定制裁: CRA可以援引GAAR（第245条）来拒绝条约规定的利益，并重新审查该交易，从而导致全额适用第十三部分规定中的扣税措施（25%），加上累积利息，以及在存在虚假文件的情况下处以50%的虚假陈述罚款。

董事个人责任: 董事仍可能因违反不列颠哥伦比亚省无限责任公司法而面临不合规风险；当忽视公司形式要件时，股东和董事的无限责任不会被限制，且个人担保或名义持有人安排会掩盖实际控制的真相。
反洗钱/注册不合规

法定制裁: 不提交文件的，不列颠哥伦比亚省注册机构可注销有限责任公司；未能遵守反洗钱义务可能导致因反复企业不合规而被处以最高达1000万加元的行政罚款，以及对董事和高级管理人员处以刑事罚款。

董事个人责任: 一个已解散的ULC会使股东对解散后产生的债务承担连带个人责任。董事若明知允许公司被用于洗钱，将根据《加拿大刑法》第462.31条面临资产没收、旅行禁令和监禁。
